# Security Policy

**React Nexus** is a client-side web arcade platform.

---

## 🔒 Security Practices

1. **Client-Side Game State:** Game loops, rendering, and high-score states run in local browser memory.
2. **Environment Variable Protection:** Secrets and API keys must never be committed to repository branches.
3. **Safe Content Delivery:** Audio assets and graphics are served from local static assets without unvetted external script loaders.
